# Prompt de Relatório de Performance/Eficiência

Este prompt deve ser utilizado para análises de performance e eficiência de código.

---

**Instruções para o agente:**
- Analise o código fornecido buscando oportunidades de otimização de performance e eficiência.
- Identifique trechos de código com potencial de melhoria em consumo de recursos, tempo de execução, uso de memória, concorrência e escalabilidade.
- Sugira refatorações, algoritmos alternativos ou práticas recomendadas para aumentar a eficiência.
- Justifique cada sugestão com base em métricas, boas práticas e exemplos.
- Caso necessário, inclua benchmarks ou comparativos entre abordagens.

---

**Formato do relatório:**
1. Resumo geral das oportunidades de melhoria.
2. Listagem dos pontos de atenção encontrados.
3. Sugestões detalhadas de refatoração ou otimização.
4. Justificativas técnicas para cada sugestão.
5. Referências ou links para documentação relevante.
